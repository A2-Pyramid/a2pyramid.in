# A2 Pyramid Edutech Pvt. Ltd. - Modern Homepage UI/UX

This is a production-quality, responsive React + Vite application built with styled-components and Lucide icons for **A2 Pyramid Edutech Pvt. Ltd.**

## Features Included
- **Sticky Navigation Bar** with mobile hamburger menu and responsive dropdown for all four services.
- **Hero Section** with clear typography and brand introduction.
- **Four Interactive Service Cards (2x2 Grid)**:
  1. Website Creation and Handling
  2. AD Comics
  3. Map My Teacher (Redirects to https://www.mapmyteacher.com/)
  4. Project Handling and Team Setup
- **About Section & Footer** with quick links, company description, social icons, and copyright.
- **Interactive Modals** for placeholder service routes.
- **Logo Preservation**: Uses the exact brand logo asset (`/public/logo.jpeg`).

---

## How to Run Locally in VS Code

1. **Extract** the downloaded ZIP file.
2. Open the extracted folder in **VS Code**.
3. Open the VS Code integrated terminal (`Ctrl + ~` or `Cmd + ~`).
4. Install dependencies:
   ```bash
   npm install
   ```
5. Run the development server:
   ```bash
   npm run dev
   ```
6. Click the local development URL (e.g., `http://localhost:5173`) in your terminal to view the website in your browser.
